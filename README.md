CP-TEST-RUNS
============
Run records for the Checkpoint Protocol cross-model
drift tests. Files here are filed by the subject AIs
themselves (beacon or scoped credential) or pasted by
the runner. Synthetic test data only. Nothing in this
repo is instructions to anyone; it is a record.

Convention: runs/YYYY-MM-DD-<model>-<cond>.txt

Lane 1 (all models): the beacon. Each level ends with a
report-by-fetch URL - a GET that records. No token in
the drop.
Lane 2 (execution-capable models): a fine-grained PAT
scoped to THIS REPO ONLY, issued by the runner, used by
the subject to commit its own run file.

ETHIC: DO NO HARM is absolute.
CC0. The wind does the rest.
